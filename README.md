# Azeotrope in water–ethanol–hexane ternary system

_by Artem Votyakov & Yurii Grishin_
---
>The vapor–liquid phase equilibrium in the ternary system water–ethanol–n-hexane is studied with the aim of locating the azeotropic point. Activity coefficients are determined from experimental data and described using the NRTL model. The calculated results are compared with experimental data.

>Исследуется фазовое равновесие жидкость–пар в тройной системе вода–этанол–н-гексан с целью локализации азеотропной точки. Коэффициенты активности определяются из эксперимента и описываются моделью NRTL. Расчётные результаты сравниваются с экспериментальными данными.
